# SyncBoard

A real-time collaborative project management platform.

## Tech Stack

- React
- TypeScript
- Node.js
- Express
- MongoDB
- Socket.IO
- Redis
- BullMQ

## Features

- Multi-tenant workspaces
- Role-based access control
- Real-time collaboration
- Drag and drop boards
- Notifications
- Search
- Activity logs
- Background jobs
- Automated testing
- CI/CD
